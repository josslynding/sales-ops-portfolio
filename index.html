Core Methodologies

MEDDPICC Qualification

8-element framework ensuring evidence-based deal progression:

  • Metrics: Quantified customer value
  • Economic Buyer: Budget authority
  • Decision Criteria/Process: Evaluation path
  • Paper Process: Procurement workflow
  • Identify Pain: Specific business pain
  • Champion: Internal advocate
  • Competition: Competitive landscape

Commit requirement: 0 Red + Max 1 Yellow

Evidence-Driven Forecasting

Replaced "Sales thinks it will close" with "Evidence supports closure":

  • Commit: 7 hard requirements validated
  • Best Case: 1 key condition pending
  • Upside: Progressing, date uncertain
  • Pipeline: Early-stage qualification

Each category has explicit entry criteria—no probability-based guessing.

Red Flag Detection System

14 automated rules with severity-based escalation:

  • 🔴 High: 24-72h response (e.g., Champion lost)
  • 🟡 Medium: 1-week action (e.g., Budget pending)
  • 🟢 Low: Monthly review (e.g., Deal age 2× cycle)

Automatic escalation to Directors when SLAs breach
